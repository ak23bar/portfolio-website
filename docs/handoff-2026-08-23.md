## Repositioning direction (decided, not yet built)

From a brainstorming pass on moving the site from student-style to professional identity.
These four decisions are recorded so they survive the session; the work is unstarted.

1. **Matrix aesthetic: split.** Professional surface becomes the default; Matrix becomes an
   opt-in mode. Not a graduation — the character stays, behind a toggle.
2. **Audience: both, hiring-weighted.** Primary surface serves hiring managers, with a clear
   secondary path for consulting inquiries.
3. **Curation: light touch, reorder only.** Explicitly scoped down. Tiering/archiving was
   recommended and declined — recorded as a deliberate deferral, not an oversight. It remains
   the single highest-leverage lever available.
4. **Hero photo: professional headshot on the pro surface, Neo image preserved inside Matrix
   mode.** *Blocked on a headshot file.* Interim fix still pending: `index.html:146` is
   `alt="Neo"`, so screen readers and search engines never learn the name.

### The split has a hard prerequisite

Measured, not estimated:

- 307 hardcoded `#00ff41` (159 CSS / 93 HTML / 55 JS)
- **0** CSS custom properties — no token layer exists
- **291** inline `style=` attributes containing hex colours

Inline styles outrank class selectors, so `body.matrix-mode` **cannot** re-theme those 291
elements. A token layer plus hoisting inline colours into classes is required *before* any
mode toggle is buildable. Modal bodies are the bulk and are highly repetitive, so the hoist
is mechanical rather than 291 judgment calls.

Also note: the loading screen ("WELCOME TO THE MATRIX") currently gates every visit, which
contradicts a hiring-weighted default. Making it Matrix-mode-only is both a positioning fix
and a real performance win.
